# SkiPlan AI

Člana skupine — Mark Repnik, Lan Gosar

Aplikacija za načrtovanje smučarskega izleta. Vnesi kraj odhoda in cilj, nato odpri načrt, vzorčno vreme ali nasvete za izbiro nastanitve.

## Zagon

V mapi projekta zaženi:

```sh
npm ci
npm start
```

Telefon in računalnik poveži v isto omrežje. Kodo QR odpri v aplikaciji Expo Go, združljivi z Expo SDK 58.
